## 1. Project Overview

AI Icon Generator is a web app that creates custom icons from text prompts, image editing, and color extraction.
It uses a FastAPI backend for AI integrations (e.g., replicate, huggingface) and image utilities, while React + Vite powers the frontend UI.

## 2. Architecture

- `backend/`
  - `app/main.py`: FastAPI app entrypoint
  - `app/api/v1/`: REST endpoints (`generation`, `edit`, `images`, `auth`, `credits`)
  - `app/services/`: business logic, file handling
  - `app/integrations/`: external model providers
  - `app/core/`: config, security, prompt registry
  - `backend/database/`: SQLAlchemy models and DB layer
  - `backend/generated_images/`: generated static assets

- `frontend/`
  - `src/pages/`: `Home`, `Gallery`, `ImageStudio`, `SmartIconGenerator`, auth pages
  - `src/components/`: charts, UI blocks
  - `src/services/api.jsx`: API integration
  - `src/layouts/`: `Navbar`, protected route handling
  - `package.json`: Vite + React dependencies

### Setup

1. Create and activate venv
   - `python -m venv .venv`
   - `.venv\Scripts\activate` (Windows)
2. Install deps
   - `pip install -r backend/requirements.txt`
3. Configure `.env` (copy from examples, not present maybe)
4. Start app
   - `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`

### Key files

- `app/main.py`
- `app/api/v1/generation.py`
- `app/api/v1/edit.py`
- `app/services/icon_generation_service.py`

## 5. Environment / Configuration

Create `.env` in backend root for secrets (example keys):

- `DATABASE_URL=sqlite:///./app.db` (or other DB)
- `SECRET_KEY=<<<secure key>>>`
- `ACCESS_TOKEN_EXPIRE_MINUTES=30`
- `REPLICATE_API_TOKEN=...`
- `HUGGINGFACE_API_TOKEN=...`
- `CLOUDINARY_URL=...` (if used)

Possible env variables in `app/core/config.py`.

## 6. Running full app (dev)

1. Backend:
   - `cd backend`
   - `uvicorn app.main:app --reload`
2. Frontend:
   - `cd frontend`
   - `npm run dev`
3. Open browser
   - Default frontend URL: `http://localhost:5173`
   - API endpoint base: `http://localhost:8000/api/v1`

## 10. Deployment

- Backend: containerize with Docker runtime
  - Expose 8000
  - Use `uvicorn --host 0.0.0.0 --port 8000`
- Frontend:
  - build and host on Netlify/Vercel/static server
  - ensure API base URL set to deployed backend
- Secure HTTPS + CORS

## 11. Troubleshooting

- 500 errors from AI provider usually due to token/key missing
- `ModuleNotFoundError` -> re-run `pip install -r backend/requirements.txt`
- `npm ERR` -> remove `node_modules`, `npm install` again
- CORS: `backend/app/core/security.py` and `app/main.py` cors config.
